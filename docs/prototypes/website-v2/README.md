## Image sources and licensing

- **No third-party images.** Every image in `assets/img/` is an original illustration generated for this prototype by `gen_illustrations.py`. It is built from basic shapes in the approved palette, with small teal and amber data accents.
- **People:** there are no photographs, real people, client logos or AI robots. Team scenes use generic silhouettes that do not depict actual ROICIANS clients, instructors or students.
- **Licence:** the illustrations are owned by the project, with no licence obligations.
- **Fonts:** Instrument Sans, Inter and Geist Mono, via Google Fonts under the SIL Open Font License.
- **Why not photography:** external image libraries are not reachable from the build environment, and the artifact viewer blocks external images. If photography is wanted for launch, use a licensed library or a commissioned shoot, with model releases.

## How v2 answers the rejected v1 screens

| v1 problem | v2 change |
|---|---|
| Looked like an LMS dashboard or a plain catalogue | Image-led layout with large illustrations, generous whitespace, fewer borders, and one clear action per block |
| Large "Program portfolio" panel listing all ten Program names in the hero | Removed. The hero is a three-slide, image-led slider (career training, corporate upskilling, advanced AI) with arrows, indicators, keyboard and swipe, and no autoplay |
| All ten Programs on the homepage, with repeated category and status on every card | The homepage shows four featured Programs in a carousel, plus a "View all programs" link. Cards carry only an image, name, short description and Explore Program |
| Programs page of plain bordered boxes and cramped text | Separate Programs page with topic-specific images of identical size, borderless cards, generous spacing, readable headings, and group filtering |
| Programs page columns | 3 columns on desktop, 2 on tablet, 1 on mobile; the four-Program group is a centred 2 × 2 |
| Amber SAMPLE badges throughout | One discreet prototype line at the top, plus a separate review-notes page |
| Text wordmark placeholder | The original ROICIANS logo (no TECH) |
| Corporate Training lacked imagery | Soft-blue section with a professional illustration and a single Talk to an Advisor action |

## QA performed (local, 2026-10-22)

**Coverage:** all four pages at 1440 px (desktop), 820 px (tablet) and 390 px (phone).

**All passed:**
- No horizontal overflow.
- Every image loads.
- No console or page errors.
- All approved fonts render.

**26 interaction checks, all passing:**
- **Hero slider:** arrows, indicators, keyboard arrows (including wrap-around), and swipe. Hidden slides are out of the tab order, and slide changes are announced to screen readers.
- **Featured carousel:** scrolls.
- **Menus:** the Log in menu opens and closes with Escape; the mobile menu opens and closes.
- **Prototype-only actions:** they show a note, and the enquiry button never submits.
- **Programs page:**
  - "View all programs" opens it;
  - its filter shows 10, 6 or 4 Programs;
  - `#specialist` deep links pre-filter it;
  - 3 / 2 / 1 columns at desktop, tablet and phone widths;
  - equal image sizes, and no repeated category labels.
- **Keyboard:** tab order runs from the review-notes link through the header to the hero, with a visible focus ring at every stop.

**Logo checks, at 1440, 820 and 390 px:**
- No TECH or divider remains in the header or footer.
- The header symbol and wordmark keep their original relative scale (57/180), and the wordmark is centred on the symbol.
- No logo image is stretched or squeezed: the aspect ratio is checked on every instance.
- The favicon's symbol pixels are identical to the crop.
- The master logo's SHA-256 is unchanged.
