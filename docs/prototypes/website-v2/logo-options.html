How the original logo is preserved

  • Master file kept unchanged: docs/brand/roicians-logo-original.png, 433 × 370 transparent PNG, SHA-256 13ecd0b8ae36b968….
  • Web copy: roicians-logo-web.png only trims the empty transparent margin.
  • Header pieces: roicians-symbol.png and roicians-wordmark.png are straight crops of the original. Pixels are not changed or resampled.
  • TECH: set in Instrument Sans, semibold, widely letter-spaced, in the original logo blue #2E496C, so it reads as a supporting label rather than part of the mark.
  • Backgrounds: the navy logo is used only on white or very light blue, never on dark backgrounds.
  • Resolution: the supplied PNG is small. It is sharp at header and footer sizes, but a vector (SVG) or larger master is recommended before launch.
